Interactive Prototype for Project Meridian

# MERIDIAN — Capability Workforce Intelligence

![Meridian Prototype](https://img.shields.io/badge/Status-Prototype_Complete-success) ![Tech Stack](https://img.shields.io/badge/Tech-HTML5%20%7C%20TailwindCSS%20%7C%20VanillaJS-blue)

**Meridian** is a single-page Decision Intelligence prototype designed specifically for the executive level (Director of Human Capital / Board of Directors). 

This application demonstrates how an enterprise-scale organization (State-Owned Enterprise) can manage a workforce transformation crisis driven by AI and IoT automation, shifting the narrative from a mass layoff threat to a data-driven redeployment strategy.

---

## 📊 Business Context & Challenges (Case Study)
This project is built upon a workforce transformation case study with the following parameters:
* **Organizational Scale:** 52,000 enterprise employees operating within a strong seniority-based culture.
* **Disruption Crisis:** 70% of the workload in the *Field Metering* division (6,000 employees) will be automated within the next 18 months due to a Smart Meter rollout. 4,200 roles are at risk of displacement.
* **Data Crisis:** 45% of employee skill records in the current HRIS (SAP/Moodle) are missing or empty.
* **Governance Constraints:** The Oracle Payroll system is restricted by ministry data governance regulations, meaning financial ROI models must rely on scenario-based assumptions rather than actual salary data.

## 💡 Strategic Solution
Meridian resolves these challenges through three architectural pillars:
1. **Taxonomy Shift (Position to Capability):** Collapsing 1,800+ rigid legacy job titles into a dynamic, defensible capability portfolio framework (adopting global standards while adapting to local enterprise nuances).
2. **Tenure-Based Inference Engine:** Utilizing employee tenure as a baseline assumption to infer missing skill data. This mitigates risk by enforcing a strict principle: *"AI-assisted insight, Human validation required"*.
3. **Redeployment Algorithm:** Matching disrupted worker profiles to emerging skill demands (e.g., *Smart Meter Ops* or *IoT Monitoring*), complete with skill gap analysis and estimated reskilling timelines.

## 🚀 Navigation Guide: Finding the "AHA" Moment
This prototype is choreographed for an executive presentation flow. To experience the key decision-making milestone (The AHA Moment), follow these steps:

1. **Open the Dashboard (Overview):** Notice the red crisis alert regarding 4,200 disrupted roles. Click the red **"Explore redeployment opportunity"** button.
2. **Redeployment Menu:** Observe how the system instantly transforms a pool of workers threatened with layoffs into transition-ready candidates. Click **"View Detail & Pathway"** on the *Smart Meter Operations* card (87% match score).
3. **The Evidence Drawer:** Pay attention to the slide-out panel on the right. This proves to executives exactly how the AI calculated the 87% score by separating *Verified* vs *Inferred* data.
4. **Transition Plan:** Click **"Add to Transition Plan"**, followed by **"Approve Cohort"**.
5. **Decision Center:** See how your approval is seamlessly recorded as a formal decision ready for execution by the Regional HR team.

## 🛠 Tech Stack
This prototype was intentionally built using a lightweight, Single-File architecture to ensure it is easily distributable, loads instantly, and can be reviewed by stakeholders without requiring backend installation.
* **Markup & Logic:** HTML5 & Vanilla JavaScript
* **Styling:** Tailwind CSS (via CDN) with interactive Dark Mode support.
* **Iconography:** Lucide Icons.
* **State Management:** Native DOM manipulation for database simulation (Pathway Data Model).
